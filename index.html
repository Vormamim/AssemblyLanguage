    Theory & instructions
    

  
    
    
    The registers: ACC, PC, Zero flag
    
    
    
      
    Three small boxes above the program listing show exactly what the CPU is holding right now:
    
      
      
        
    • ACC (accumulator) — the chip's only general-purpose register. Every LOAD, ADD and SUB reads or writes it, so it's always the current "working value" — and its 8 bits are shown live underneath it.
      • 
        
    • PC (line) — the program counter. It's the line number the CPU is about to run next — the same line highlighted in the listing below. It shows — once the program halts.
      • 
        
    • Zero flag — a tiny yes/no switch: is ACC exactly 0 right now, or not? See below.
      • 
      
    
      
    All three flash violet whenever they change, so you can watch them update one Step at a time.
    
      
    The Zero flag, step by step: it doesn't move data or do maths — its only job is to answer one question. Every time LOAD, ADD or SUB runs, the CPU checks: "did ACC just become exactly 0?" Yes → the flag flips to 1. No → it flips to 0. That's the whole instruction.
    
      
    Here's why that matters, using the Countdown Loop example: SUB #1 shrinks the counter by one every time round the loop. The moment the counter reaches 0, the Zero flag flips to 1. The very next instruction, JZ 10, checks that flag, sees a 1, and jumps straight to HALT — instead of looping again. Without the Zero flag, JZ would have no way of knowing the counter had run out.
    
    
    
  
    

  
    
    
    Real chips have more than one register — meet the Z80
    
    
    
      
    LoFiCPU-8 only has one general-purpose register, ACC, on purpose — every value has to pass through the same spot, so "process" is always easy to point at. Real chips almost never stop at one.
    
      
    Take the Zilog Z80 (1976) — the chip inside the ZX Spectrum, the original Game Boy, the Sega Master System, and thousands of arcade machines. Instead of a single ACC, it has an accumulator plus six more general-purpose 8-bit registers, all usable at the same time:
    
      
    
        
    RegisterRole
    
        
          
    Athe accumulator — same job as LoFiCPU-8's ACC
    
          
    B, C, D, E, H, Lsix more general-purpose registers, free to hold values alongside A
    
          
    BC, DE, HLthose same six, paired up into three 16-bit registers — handy for addresses and bigger numbers
    
            
      
    
      
    Why does that matter? Look back at Multiply by Repeated Addition or Sum from 1 to N — notice how many LOAD/STORE instructions exist purely to shuffle a value in and out of ACC, because ACC is the only place to put anything. A chip with a spare B or C register could just leave that value sitting there instead — fewer instructions, less memory traffic, for exactly the same job.
    
      
    The trade-off: more registers means more to keep track of, and a lot more to explain before "the CPU is just following instructions" starts to make sense. That's the whole reason LoFiCPU-8 stops at one.
    
    
    
  
    

  
    
    
    How to use this IDE
    
    
    
      
    1. Click an example button to load a ready-made program, or type your own into the editor.
    
      
    2. Click Assemble & Load to check your code for errors and get the chip ready to run.
    
      
    3. Click Step to run one instruction at a time and watch the highlighted line, or click Run to play automatically at the speed you choose.
    
      
    4. Right after loading, click any memory cell on the left to change its starting value — that's your input. Cells lock once you start stepping; click Reset to unlock them again.
    
    
    
  
    

  
    
    
    The IPO model
    
    
    
      
    Every computer, from a calculator to a supercomputer, does the same three things, over and over:
    
      
      
        
    • Input — data goes in. Here, that's the memory cells you set before running.
      • 
        
    • Process — the CPU follows instructions one at a time, using the accumulator (ACC) as its scratchpad.
      • 
        
    • Output — a result comes out. Here, that's anything printed with OUT or OUTC.
      • 
      
    
      
    The three panels on the page are colour-coded to match: teal for Input, violet for Process, orange for Output.
    
    
    
  
    

  
    
    
    Binary — the bits underneath
    
    
    
      
    Every memory cell and the ACC register are really just 8 bits (a "byte") underneath the decimal number you see. Watch them under the ACC display, and as little dots under each memory cell.
    
      
    Each bit is worth twice the one before it — reading left to right: 128, 64, 32, 16, 8, 4, 2, 1. A lit bit means 1; add up the lit bits' place values and you get the decimal number.
    
      
    Negative numbers use a trick called two's complement — for example, −1 is all eight bits lit: 11111111.
    
      
    The bits pulse whenever a value changes — that's the CPU actually rewriting memory, in front of you.
    
      
    This isn't just for show: LoFiCPU-8 really is an 8-bit chip. ACC and every memory cell are clamped to -128–127 — add 1 to 127 and it genuinely becomes -128, not 128. Try the Overflow! example to watch it happen.
